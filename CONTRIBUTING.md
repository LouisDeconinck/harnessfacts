# Contributing

Start with [the contribution guide](docs/contributing.md). Run `bun run lint`, `bun run typecheck`, `bun test`, `bun run validate`, and `bun run build` before a pull request. No paid agent credentials are required for those checks.

Keep changes small and local to an adapter or test. Add your GitHub handle through optional `authors` metadata for attribution. Do not manufacture observations, conflate documentation with runtime behavior, or hide failed runs. Any semantic fixture/evaluator change needs a test version bump and historical version registration. All contributions are Apache-2.0.
