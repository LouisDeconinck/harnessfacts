# Aider adapter

Invocation follows the [official CLI reference](https://aider.chat/docs/config/options.html) (consulted 2026-09-08). Platform flags describe intended adapter targets, not verified support. Runs use a temporary home and explicit credentials; see [security model](../../docs/security-model.md). Unmapped interactions are SKIPPED, not evidence of unsupported capability. The evaluator is shared across agents.
