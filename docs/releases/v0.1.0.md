# HarnessFacts v0.1.0

Release notes prepared for the first public release; packages and tag are not published by this preparation pass.

HarnessFacts is an open compatibility suite for coding agents: tiny deterministic tests, exact versions/environments, inspectable evidence, and separate documentation claims. No subjective judging, overall scores or rankings.

- **12 executable tests:** root/nested/precedence instructions; skill discovery; MCP stdio/HTTP; headless and structured execution; paired exit-code semantics; Git worktree and bounded repository-edit behavior.
- **73 preserved real runs:** Codex 0.153.4, OpenCode 1.18.29 and Antigravity CLI 1.1.27 on the recorded Linux x64 environment. History includes failures and execution errors, not only successes. See [initial observations](../initial-observations.md) for dates, exact environment and limitations.
- **`harnessfacts@0.1.0`:** Bun CLI with packaged fixtures/adapters, diagnostics, local execution, inspection and evidence validation.
- **`@harnessfacts/data@0.1.0`:** dependency-free ESM and JSON snapshots with TypeScript declarations and public query exports; [external Node/TypeScript example](../../examples/data-consumer).
- **`LouisDeconinck/harnessfacts/check@v0.1.0`:** credential-free compatibility-data assertion. All requested capabilities use one agent version and full recorded environment; UNKNOWN is distinct from FAIL. It does not execute an agent downstream.
- **Contribute one observation:** clone, install, authenticate an existing agent, run doctor and one test, inspect evidence, validate, submit a PR. No core-code change required; [workflow](../contributing.md).

## Limits

Evidence covers recorded configurations only—not universal, future-version or cross-platform support. Antigravity CLI is independent of Gemini CLI. Claude Code, Gemini CLI and Aider runtime status remains unknown; Copilot CLI is planned/documented, not verified. Hooks and Windows process-tree cleanup remain deferred. Scope/worktree results are not security guarantees. Model defaults/settings are not fully captured as structured configuration fields; do not treat these observations as controlled model comparisons.

The Action uses its pinned release snapshot without a freshness guarantee. Compact website/data summaries show individual completed observations; the Action is stricter and requires all current tests per capability in one configuration. Project CI never runs paid coding agents. No telemetry, hosted backend, database or ranking system is introduced.
