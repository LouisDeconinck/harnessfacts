# Skill discovery

Measures discovery and use of a repository skill. The expected token exists only in its skill body.

Version: 1.0.0. The fixture is tiny and the evaluator uses exact tokens, not model judgment. PASS requires file-content: `SKILL`. A completed execution without this is FAIL; execution problems are ERROR. Observations apply only to the recorded configuration, agent version, environment, and date. Inspect `fixture/`, `test.yaml`, and `evaluate.ts` for the exact procedure.
